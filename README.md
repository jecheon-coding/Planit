# Planit

일정과 할일을 함께 관리하는 개인 스케줄 앱입니다. 빌드 없이 HTML/CSS/JavaScript만으로 동작하며, 데이터는 브라우저 `localStorage`에 저장됩니다.

## 실행

ES Modules를 쓰기 때문에 `index.html`을 파일로 직접 열면 동작하지 않습니다. 정적 서버로 여세요.

```bash
npm start            # npx serve → http://localhost:5173
# 또는
python -m http.server 5173
```

VS Code를 쓴다면 Live Server 확장으로 `index.html`을 열어도 됩니다.

## 주요 기능

- **일정 + 할일 통합**: 일정(시작~종료, 종일)과 할일(마감일/시각 선택, 완료 체크)을 한 화면에서 관리
- **일간 타임라인 / 월간 캘린더**: 겹치는 일정 자동 열 배치, 현재 시각선, 지연된 할일 표시, `+N 더보기`
- **카테고리 색상·필터**: 업무/개인/학습 색상 변경, 카테고리·종류·완료 여부 필터
- **빠른 입력**: `내일 오후 3시 팀 회의 #업무`처럼 입력하면 날짜·시간·카테고리를 자동 인식
- **할일 목록**: 지연됨 / 오늘 / 예정 / 언제든 / 완료됨으로 묶어 보기
- **모바일 대응**: 하단 탭바, 새 일정 플로팅 버튼, 좌우 스와이프로 날짜 이동, 전체 화면 편집 창, 홈 화면 추가

## 휴대폰에서 쓰기

같은 Wi-Fi에서 PC의 IP로 접속하면 됩니다 (예: `http://192.168.0.10:5173`).
`npx serve`는 기본적으로 외부 접속을 허용하며, 처음 실행 시 Windows 방화벽 허용 창이 뜰 수 있습니다.

- **iPhone (Safari)**: 공유 버튼 › 홈 화면에 추가
- **Android (Chrome)**: 메뉴 › 홈 화면에 추가

데이터는 기기마다 따로 저장됩니다. 다른 기기로 옮길 때는 설정 › 내보내기/가져오기를 사용하세요.

**지원 브라우저**: iOS Safari 16.4+, Android Chrome 111+, 최신 Chrome·Edge·Firefox·Safari

### 빠른 입력 예시

| 입력 | 결과 |
|------|------|
| `내일 오후 3시 회의` | 내일 15:00–16:00 일정 (업무로 추론) |
| `다음주 화요일 10시~12시 스터디 #학습` | 다음주 화 10:00–12:00, 학습 |
| `3시 치과 1시간 반` | 오늘 15:00–16:30 |
| `모레 종일 워크숍` | 모레 종일 일정 |
| `금요일까지 보고서 제출` | 금요일 마감 할일 |
| `할일 우유 사기` / `- 책 반납` | 마감 없는 할일 |

`Enter` 저장 · `Shift+Enter` 상세 편집 후 저장 · `Esc` 취소

### 단축키

`/` 빠른 입력 · `N` 새 항목 · `D` 일간 · `M` 월간 · `L` 할일 · `T` 오늘 · `←` `→` 이전/다음

## 테스트
