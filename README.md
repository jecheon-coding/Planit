# Planit

일정과 할일을 함께 관리하는 개인 스케줄 앱입니다. 빌드 없이 HTML/CSS/JavaScript만으로 동작하며, 데이터는 브라우저 `localStorage`에 저장됩니다.

## 실행

ES Modules를 쓰기 때문에 `index.html`을 파일로 직접 열면 동작하지 않습니다. 정적 서버로 여세요.

```bash
npm start            # npx serve → http://localhost:5173
# 또는
python -m http.server 5173
```

VS Code를 쓴다면 Live Server 확장으로 `index.html`을 열어도 됩니다.

## 주요 기능

- **일정 + 할일 통합**: 일정(시작~종료, 종일)과 할일(마감일/시각 선택, 완료 체크)을 한 화면에서 관리
- **일간 타임라인 / 월간 캘린더**: 겹치는 일정 자동 열 배치, 현재 시각선, 지연된 할일 표시, `+N 더보기`
- **카테고리 색상·필터**: 업무/개인/학습 색상 변경, 카테고리·종류·완료 여부 필터
- **빠른 입력**: `내일 오후 3시 팀 회의 #업무`처럼 입력하면 날짜·시간·카테고리를 자동 인식
- **할일 목록**: 지연됨 / 오늘 / 예정 / 언제든 / 완료됨으로 묶어 보기
- **반복 일정** (Google Calendar 방식): 매일 / 매주 요일 / 매월 N일·N번째 요일 / 매년 / 주중 매일 / 맞춤(간격·요일·종료). 회차를 고칠 때 "이 일정 / 이 일정 및 향후 일정 / 모든 일정" 선택
- **반복 할일** (Google Tasks 방식): 완료하면 다음 회차가 나타남. 할일 목록에는 지금 해야 할 회차 하나만 보이고, 빼먹어도 지연이 쌓이지 않음
- **알림** (네이버 캘린더 방식): 항목마다 여러 개 (정시, 10분 전, 1일 전… / 종일은 당일·1일 전 오전 9시). 화면 위 알림 배너 + 소리·진동, 설정에서 켜면 휴대폰·PC 알림
- **장소**: 장소 입력 + 네이버 지도로 바로 보기
- **메모 사진**: 사진(카메라·앨범) 최대 10장, 눌러서 크게 보기. 자동으로 줄여 저장, 백업 파일에도 포함
- **공휴일 표시**: 설날·추석 연휴, 대체공휴일 포함 (2024–2030)
- **검색**: 제목·메모·장소 (`F`)
- **복제 / 캘린더 앱에 추가**: 같은 내용으로 새 항목, 휴대폰·PC 기본 캘린더로 보내기(.ics, 알림 포함)
- **모바일 대응**: 하단 탭바, 새 일정 플로팅 버튼, 좌우 스와이프로 날짜 이동, 전체 화면 편집 창, 홈 화면 추가, 오프라인 실행

## 휴대폰에서 쓰기

같은 Wi-Fi에서 PC의 IP로 접속하면 됩니다 (예: `http://192.168.0.10:5173`).
`npx serve`는 기본적으로 외부 접속을 허용하며, 처음 실행 시 Windows 방화벽 허용 창이 뜰 수 있습니다.

- **iPhone (Safari)**: 공유 버튼 › 홈 화면에 추가
- **Android (Chrome)**: 메뉴 › 홈 화면에 추가

데이터는 기기마다 따로 저장됩니다. 다른 기기로 옮길 때는 설정 › 내보내기/가져오기를 사용하세요.

### 알림을 휴대폰 알림으로 받으려면

앱이 열려 있으면 화면 위에 알림 배너가 뜹니다. 앱을 보고 있지 않을 때도 휴대폰·PC 알림으로 받으려면 설정 › 알림 › **휴대폰·PC 알림**을 켜세요. 단, 브라우저 제약이 있습니다.

| 상황 | 휴대폰·PC 알림 |
|------|----------------|
| `http://192.168.x.x:5173`처럼 **HTTPS가 아닌 주소** | ✗ (앱 안 배너만) — GitHub Pages·Netlify 같은 HTTPS 호스팅에 올리면 가능 |
| PC의 `http://localhost:5173` | ✓ |
| Android Chrome (HTTPS) | ✓ |
| iPhone (HTTPS) | 홈 화면에 추가한 앱에서만 ✓ (iOS 16.4+) |
| 앱(탭)을 완전히 닫은 경우 | ✗ — 서버가 있어야 가능 |

꼭 받아야 하는 일정은 항목을 열어 **캘린더 앱에 추가**를 누르세요. .ics 파일을 열면 휴대폰 기본 캘린더에 들어가고, 알림도 그 캘린더 앱이 보내 줍니다.

**지원 브라우저**: iOS Safari 16.4+, Android Chrome 111+, 최신 Chrome·Edge·Firefox·Safari

### 빠른 입력 예시

| 입력 | 결과 |
|------|------|
| `내일 오후 3시 회의` | 내일 15:00–16:00 일정 (업무로 추론) |
| `다음주 화요일 10시~12시 스터디 #학습` | 다음주 화 10:00–12:00, 학습 |
| `3시 치과 1시간 반` | 오늘 15:00–16:30 |
| `모레 종일 워크숍` | 모레 종일 일정 |
| `금요일까지 보고서 제출` | 금요일 마감 할일 |
| `할일 우유 사기` / `- 책 반납` | 마감 없는 할일 |
| `매주 월요일 9시 팀 회의` | 매주 월요일 반복 일정 |
| `격주 금요일 오후 3시 스터디` | 2주마다 금요일 |
| `매월 15일 월세` | 매월 15일 종일 반복 |
| `평일 9시 스탠드업` | 월~금 반복 |
| `매주 월요일 9시 회의 12월 31일까지` | 12/31까지만 반복 |
| `매주 금요일까지 주간 보고서 제출` | 매주 금요일 반복 할일 |
| `- 매일 영어 단어 외우기` | 매일 반복 할일 |
| `매월 25일 할일 카드값 확인` | 매월 25일 반복 할일 |
| `내일 오후 3시 회의 @강남역` | 장소: 강남역 |
| `모레 2시 치과 1시간 전에 알려줘` | 1시간 전 알림 (`10분 전 알림`, `하루 전 알림`, `정시 알림`도 가능) |
| `내일 3시 회의 알림 없이` | 기본 알림(10분 전)도 끔 |

`Enter` 저장 · `Shift+Enter` 상세 편집 후 저장 · `Esc` 취소

### 단축키

`/` 빠른 입력 · `N` 새 항목 · `D` 일간 · `M` 월간 · `L` 할일 · `T` 오늘 · `F` 검색 · `←` `→` 이전/다음

## 테스트

```bash
npm test             # Node에서 파서·날짜·반복·알림·공휴일·.ics 단위 테스트 실행
```

브라우저에서는 서버를 띄운 뒤 `/tests/test.html`을 열면 됩니다.

## 백업

사이드바 › 설정 › **내보내기**로 JSON 파일(메모 사진 포함)을 받고, **가져오기**로 복원합니다.
**캘린더 파일(.ics)** 은 모든 일정을 구글·아이폰·삼성 캘린더 등으로 옮길 때 씁니다.

설계 문서는 [DESIGN.md](DESIGN.md)를 참고하세요.
